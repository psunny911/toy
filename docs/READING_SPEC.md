# 소리 내어 읽기 — 기능 명세 (v0.1, 웹 MVP)

## 1. 요구사항

1. 학습할 문장을 **CSV**로 넣는다 (영어 문장, 뜻).
2. 영어 문장을 소리 내어 읽으면 **음성 인식**으로 알아듣고 채점한다.
3. **정확도 80% 이상**이면 통과 → 다음 문장으로 자동으로 넘어간다.
4. 보기 방식 3가지: **전체 문장** / **일부 단어 숨기기** / **뜻만 보기(전체 문장 숨기기)**.

## 2. 기술 선택

서버·외부 라이브러리 없이 브라우저 API만 쓴다.

| 요구 | API | 지원 |
| --- | --- | --- |
| 음성 인식 | `SpeechRecognition` / `webkitSpeechRecognition` (`lang=en-US`, 중간 결과, 후보 5개) | Chrome·Edge(Android/PC), Safari 14.5+ (iOS는 Siri 켜짐 필요). Firefox ✕ |
| 문장 읽어 주기 | `speechSynthesis` | 전부 |
| CSV 읽기 | `<input type=file>` + `TextDecoder` (UTF-8, 실패 시 EUC-KR) | 전부 |
| 저장 | `localStorage` (문장 목록·진행·보기 방식) | 전부 |

## 3. 채점 규칙 (`js/score.js`)

1. 목표 문장과 인식 결과를 단어(토큰)로 나눈다. 대소문자·문장부호는 무시한다.
2. 같은 말로 보는 것: 축약형(`I'm` = `I am`, `don't` = `do not`, `can't` = `can not`, `let's` = `lets` = `let us`),
   숫자(`2` = `two`, `21st` = `twenty first`, `7:30` = `seven thirty`, `1,500`), `okay` = `OK`, `&` = `and`,
   구어체 줄임말(`gonna` = `going to`, `wanna` = `want to`, `gotta` = `got to`, `kinda` = `kind of`, `gimme`, `lemme`, `dunno` 등).
   5글자 이상 단어는 철자 한 글자 차이(`colour`/`color`)까지 봐준다 (9글자 이상은 두 글자).
3. 최장 공통 부분열(LCS)로 순서를 지켜 맞춘 뒤, **정확도 = 맞게 읽은 목표 단어 수 ÷ 목표 단어 수**.
   군말(um, uh)이나 반복은 감점하지 않는다. 순서가 뒤바뀌면 맞지 않는다.
4. 브라우저가 준 인식 후보(최대 5개) 중 **가장 높은 점수**를 쓴다.
5. 0.8 이상이면 통과. 말하는 도중 모든 단어가 맞으면 말이 끝나길 기다리지 않고 바로 채점한다.

## 4. 화면

- 상단: 진행(현재/전체 — 누르면 번호 입력으로 이동, 통과 수), `⏮ 처음으로`(첫 문장으로 이동, 통과 기록은 유지), 보기 방식 3단 버튼, `목록`, `문장 불러오기`
- 목록: 번호 입력 → 이동(맨 위 고정), 문장을 눌러 이동, 열면 현재 문장 위치로 스크롤
- 카드: 뜻 + 영어 문장, `듣기`(TTS), `정답 보기`(숨김 모드), `다른 단어 숨기기`(일부 숨김 모드)
- 결과: 정확도 %, 안내 문구, "들린 문장"
- 하단 고정: `◀ 이전` · 마이크 · `건너뛰기 ▶`(통과한 문장은 `다음 ▶`)
- PC 단축키: Space = 마이크, ←/→ = 이전/다음

### 보기 방식

| 방식 | 처음 | 읽은 뒤 |
| --- | --- | --- |
| 전체 문장 | 문장 전체 | 맞은 단어 초록, 놓친 단어 빨강 물결 밑줄 |
| 일부 단어 숨기기 | 단어의 약 40%(3글자 이상 우선, 최소 1개)를 글자 수만큼 빈칸으로 | 맞게 읽은 빈칸은 드러나고, 놓친 빈칸은 빨간 줄 |
| 뜻만 보기 | 뜻과 "단어 N개"만 | 단어 자리가 빈칸으로 나타나고 맞힌 단어만 드러남 |

- 숨길 단어는 문장 내용으로 시드를 정해 매번 같다. `다른 단어 숨기기`로 바꿀 수 있다.
- 통과하면 모든 방식에서 문장 전체가 초록으로 보이고 1.6초 뒤 다음 문장.
- 마지막 문장 다음에는 완료 화면(통과 수·읽은 횟수, `못 넘은 문장 다시`, `처음부터 다시`).
