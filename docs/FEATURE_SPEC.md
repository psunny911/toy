# 사진 콜라주 앱 — 기능 명세서 (v0.1, MVP)

## 1. 개요

여러 장의 사진을 골라 그리드 템플릿에 배치하고, 테두리/간격을 조절한 뒤
하나의 이미지로 저장하는 웹 기반 앱. 순수 HTML/CSS/JavaScript(Canvas API)로
구현하며 빌드 과정 없이 폰 브라우저에서 파일을 열면 바로 동작한다.

## 2. 기술 스택

- **런타임**: 모바일 브라우저(Android Chrome 기준). 별도 빌드/설치 불필요
- **구현**: 순수 HTML/CSS/JavaScript 단일 파일 (프레임워크·외부 의존성 없음)
- **사진 선택**: `<input type="file" accept="image/*" multiple>` — 네이티브 갤러리 피커 호출
- **합성/렌더링**: Canvas 2D API
- **저장**: `canvas.toBlob()` → `<a download>` (기본) / `navigator.share()` (지원 시 공유 시트로 저장)
- **오프라인 동작**: 외부 네트워크 요청 없음. 로컬 파일로 열어도 100% 동작

향후 스토어 배포가 필요해지면 Capacitor 등으로 이 웹 앱을 네이티브 래핑하는
방향을 고려한다 (이번 스코프에는 포함하지 않음).

## 3. 화면 흐름

```
[시작 화면]
   ↓ "사진 선택" 버튼
[갤러리 피커] (OS 네이티브)
   ↓ 3~4장 선택
[편집 화면]
   - 출력 비율 5종 중 선택 (1:1 / 16:10 가로·세로 / 3:4 가로·세로)
   - 그리드 템플릿 4종 중 선택 (2분할 가로·세로 / 3분할 / 4분할)
   - 선택된 사진이 템플릿 슬롯에 자동 배치
   - 슬롯 2개 탭하면 사진 위치 스왑, 드래그로 팬, 두 손가락으로 핀치 줌
   - 테두리 두께 슬라이더
   - 모서리 둥글기 슬라이더
   ↓ "저장" 버튼
[저장 완료] → 다운로드 또는 공유 시트
```

## 4. 기능 상세

### 4.1 사진 선택 (멀티)
- 파일 입력으로 사진 3~4장 선택 (최소 2장, 최대 4장)
- 선택 즉시 편집 화면으로 전환, 썸네일 미리보기 표시
- 4장 초과 선택 시 앞 4장만 사용 (에러 없이 조용히 잘라냄)

### 4.2 그리드 템플릿
MVP 템플릿 4종 (버튼 4개):
1. **2분할 가로** — 좌우로 나란히 배치 (사진 2장)
2. **2분할 세로** — 상하로 나란히 배치 (사진 2장)
3. **3분할** — 위 1장 + 아래 2등분 (사진 3장)
4. **4분할** — 2x2 격자 (사진 4장)

- 선택한 사진 수에 맞는 템플릿만 활성화 (예: 2장 선택 시 "2분할 가로"/"2분할 세로" 둘 다 선택 가능,
  3장이면 3분할만, 4장이면 4분할만)
- 사진 2장을 선택하면 기본값은 "2분할 가로"이며, 언제든 "2분할 세로"로 바꿀 수 있음
- 템플릿은 Canvas 위에 슬롯 좌표(x, y, width, height)로 정의, 각 슬롯에 사진을
  `object-fit: cover` 방식으로 크롭하여 채움
- 템플릿을 바꾸면 슬롯별 팬/줌 상태는 초기화되지만, 테두리 두께·모서리 둥글기 설정은 유지됨

### 4.3 사진 위치 조정

**(a) 슬롯 간 사진 교환**
- 편집 화면에서 슬롯 A를 탭 → 하이라이트 → 슬롯 B를 탭 → 두 사진 위치 교환
- 드래그 앤 드롭으로 슬롯을 옮기는 것은 MVP 범위 밖 (추후 확장)
- 스왑이 일어나면 두 슬롯의 팬/줌 상태는 기본값(줌 1배, 중앙 정렬)으로 초기화

**(b) 슬롯 내부에서 사진 위치 조정 (팬 + 핀치 줌)**
- 각 슬롯은 사진을 `cover` 방식으로 크롭해서 채우기 때문에, 사진에서 어느 부분이
  보일지를 사용자가 직접 정할 수 있어야 함
- **팬**: 슬롯 안에서 한 손가락으로 드래그하면 크롭 영역이 드래그 방향으로 이동
- **핀치 줌**: 슬롯 안에서 두 손가락으로 오므리거나 벌리면 해당 슬롯 사진만 확대/축소
  (줌 배율 범위 1.0배~3.0배, 1.0배 = 슬롯을 빈틈없이 덮는 최소 배율)
- 줌이 커질수록 팬 가능 범위도 함께 늘어남 (이동 가능 최대치는 매 프레임 현재 줌 기준으로 재계산)
- 사진이 슬롯 경계 밖으로 빈 공간을 남기지 않도록 팬 이동 범위를 슬롯 크기·줌 배율 기준으로 clamp
- 제스처 판별: 탭(움직임 거의 없는 단일 터치)은 (a)의 슬롯 스왑, 한 손가락 이동은 팬, 두 손가락 이동은
  핀치 줌으로 처리 → 터치 포인트 개수와 이동 거리 임계값으로 세 제스처를 구분

### 4.4 테두리 / 모서리 조절
- 테두리 두께 슬라이더 (0~20px, 실시간 미리보기)
- 모서리 둥글기 슬라이더 (0~30px, 실시간 미리보기)
- 배경(테두리) 색상은 흰색 고정 (MVP 범위 밖: 색상 선택)

### 4.5 출력 이미지 비율 선택
버튼 5개로 최종 저장 이미지의 가로세로 비율을 고른다:

1. **1:1** — 정사각형
2. **16:10 가로** — 가로가 긴 와이드
3. **16:10 세로** — 세로가 긴 와이드 (16:10을 90도 회전)
4. **3:4 가로** — 가로가 긴 (실제 비율 4:3)
5. **3:4 세로** — 세로가 긴 (실제 비율 3:4, 일반 사진 세로 비율)

- 캔버스 픽셀 해상도는 긴 변 기준 1080px로 고정하고, 짧은 변은 비율에 맞춰 계산
  (예: 16:10 가로 → 1080×675, 3:4 세로 → 810×1080)
- 그리드 템플릿(4.2)은 캔버스 크기에 비례해서 다시 계산되므로 어떤 비율을 골라도 같은 템플릿을
  그대로 쓸 수 있음
- 비율을 바꾸면 슬롯별 팬/줌 상태는 초기화되지만, 선택한 템플릿·테두리·모서리 설정은 유지됨
- 5종 프리셋 외의 자유 비율 입력은 MVP 범위 밖

### 4.5 저장
- "저장" 버튼 클릭 → Canvas를 PNG로 렌더링
- `navigator.share`(파일 공유) 지원 시 공유 시트 노출 → "사진에 저장" 선택 가능
- 미지원 시 `<a download="collage.png">` 로 다운로드 폴더에 저장
- 저장 성공 시 짧은 완료 메시지 표시

## 5. MVP 범위 밖 (향후 확장)

- 스티커 / 텍스트 삽입, 자유 드래그·리사이즈·회전
- 필터(흑백/세피아/빈티지 등)
- 드래그 앤 드롭으로 슬롯 자체를 재배치 (슬롯 간 사진 교환은 4.3(a)에서 탭으로 지원)
- 템플릿 종류 추가, 테두리 색상 커스터마이징
- PWA 설치(홈 화면 추가, 오프라인 매니페스트)

## 6. 비기능 요구사항

- 인터넷 연결 없이 100% 동작 (외부 리소스 로드 없음)
- 세로 화면(모바일) 기준 반응형 레이아웃
- 별도 서버/백엔드 없음 — 모든 처리는 클라이언트(브라우저) 내에서 완결

## 7. 보안 원칙

- **외부 라이브러리 미사용**: CDN 스크립트, npm 패키지 등 검증되지 않은 third-party 코드를
  포함하지 않는다. 순수 HTML/CSS/JS + 브라우저 표준 API만 사용
- **인젝션 방지**: 파일명 등 사용자/파일 유래 문자열을 화면에 표시할 때 `innerHTML`을 쓰지 않고
  `textContent`/DOM API만 사용. `eval`, `Function()`, 문자열 기반 동적 코드 실행 금지
- **입력 검증**: 선택된 파일이 실제 이미지(`file.type.startsWith('image/')`)인지 확인 후에만 처리
- **리소스 범위 제한**: 이미지는 로컬 `File`/`Blob`에서 생성한 Object URL만 사용, 원격 URL을
  fetch하거나 렌더링하지 않음. 사용이 끝난 Object URL은 `URL.revokeObjectURL`로 해제
- **CSP**: `index.html`에 `default-src 'self'; script-src 'self'; object-src 'none'` 수준의
  Content-Security-Policy 메타 태그를 적용해 방어 계층 추가

## 8. 테스트 하네스

- 순수 로직(그리드 슬롯 계산, 팬/줌 clamp, 탭·팬·핀치 제스처 판별, 슬롯 스왑 상태 전이)은
  DOM/Canvas와 분리된 순수 함수로 작성하여 유닛 테스트 가능하게 함
- 테스트 러너는 Node.js 내장 `node:test` + `node:assert/strict` 사용 (외부 테스트 프레임워크
  미사용, 별도 설치 불필요)
- 실행: `node --test test/`
