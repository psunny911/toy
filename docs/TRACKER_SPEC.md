# 데일리 트래커 — 기능 명세서 (v0.1, 웹 MVP)

## 1. 개요

영어 학습, 영양제, 운동 등 매일의 습관을 기록하고 일·주·월 단위로 돌아보는 트래커.
1단계는 웹(PWA)으로 만들어 실제로 써 보고, 괜찮으면 같은 코드를 네이티브 앱으로 감싼다.

## 2. 디자인

- 파스텔 톤. 주 색은 **파스텔 블루 `#A7C7E7`** (탭/버튼/진행 링/달력 전체 보기)
- 트래커별 색상 8종: 블루, 민트, 핑크, 레몬, 라벤더, 피치, 스카이, 세이지
- 파스텔 배경 위 글자는 흰색 대신 진한 남색(`#1F3F63`)으로 대비 확보
- 모바일 우선 (최대 폭 560px), 하단 탭바, 바텀시트형 편집 화면 — 앱 전환 시 UI를 그대로 쓰도록

## 3. 트래커

| 항목 | 설명 |
| --- | --- |
| 이름 / 아이콘(이모지) / 색상 | 아이콘 추천 목록 제공 |
| 기록 방식 | **체크**: 했다/안 했다 (예: 영양제) · **수치**: 하루 목표·단위·+버튼 단위 (예: 영어 30분, 10분씩) |
| 빠르게 시작하기 | 영어 학습, 영양제, 운동, 물 마시기, 독서, 영어 단어 프리셋 |
| 관리 | 편집, 삭제(기록 함께 삭제), 순서 변경. 기록 방식을 바꾸면 기존 기록을 새 방식으로 변환 |

## 4. 화면

- **일간**: 하루 달성률 링 + 트래커 카드. 체크형은 카드를 눌러 토글, 수치형은 −/+ 버튼 또는
  숫자를 눌러 직접 입력. 오늘 화면에는 🔥 연속 기록 표시. 지난 날짜도 수정 가능
- **주간**: 월~일 7칸 그리드. 수치형은 목표 대비 진행만큼 칸이 아래부터 차오름.
  체크형 칸은 바로 토글, 수치형 칸은 그날 일간 화면으로 이동. 트래커별 달성 일수·합계, 주간 달성률
- **월간**: 달력. "전체"는 하루 달성률을 파스텔 블루 농도로, 트래커를 고르면 그 트래커 색으로 표시.
  통계: 평균 달성률 / 모두 달성한 날 / 기록한 날 · 트래커별 달성률, 현재·최장 연속, 월 합계
- 공통: ‹ › 또는 좌우 스와이프로 기간 이동(미래로는 이동 불가), "오늘" 버튼으로 복귀

## 5. 집계 규칙

- 달성: 값 ≥ 목표 (체크형 목표 = 1)
- 트래커 시작일 = 생성일과 가장 이른 기록 중 빠른 날. 시작일 이전·오늘 이후는 달성률 분모에서 제외
- 현재 연속: 오늘을 아직 안 했으면 어제부터 센다 (하루가 끝나기 전에 끊기지 않게)
- 한 주는 월요일 시작

## 6. 데이터

```json
{
  "version": 1,
  "trackers": [{ "id": "…", "name": "영어 학습", "emoji": "📚", "color": "#A7C7E7",
                 "type": "count", "goal": 30, "step": 10, "unit": "분", "createdAt": "2026-10-11" }],
  "entries": { "2026-10-11": { "<trackerId>": 20 } }
}
```

- 이 기기의 localStorage에 저장. 서버·계정 없음, 외부 네트워크 요청 없음
- 설정 › 백업 내보내기/가져오기(JSON). 가져올 때는 알려진 필드만 골라 검증 후 교체

## 7. 앱 전환 계획

웹에서 써 보고 괜찮으면 다음 순서로 옮긴다.

1. **PWA 설치 (지금 가능)** — GitHub Pages 등 https에 올리고 "홈 화면에 추가". 오프라인 동작
2. **Capacitor로 래핑** — `tracker/` 폴더를 그대로 webDir로 사용해 Android/iOS 앱 빌드
   - `storage.js`만 Capacitor Preferences(또는 SQLite)로 교체. `loadData/saveData` 시그니처 유지
   - 기존 웹 사용자의 기록은 백업 JSON으로 이전
3. **앱에서만 가능한 기능 추가 후보**
   - 리마인더 알림 (Local Notifications: 예 "영양제 드셨나요?" 매일 오전 9시)
   - 홈 화면 위젯 (오늘 달성 현황, 원탭 체크)
   - 햅틱 피드백 (지금은 `navigator.vibrate`로 대체)
   - 기기 간 동기화 / 클라우드 백업
