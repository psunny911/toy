# 카운터 — 기능 명세 (v0.1, 웹 MVP)

## 1. 요구사항

1. 셀 **항목**을 여러 개 만들고, 항목마다 카운트를 따로 관리한다.
2. 카운트는 **스테퍼**(− / ＋)로 올리고 내린다.

## 2. 동작

| 동작 | 결과 |
| --- | --- |
| ＋ / − 탭 | 항목의 `스테퍼 단위`만큼 올리거나 내린다 (기본 1) |
| ＋ / − 길게 누르기 | 0.4초 뒤부터 0.09초마다 연속으로 움직인다 |
| 숫자 탭 | 편집 시트를 열고 `현재 값`에 바로 입력 |
| 항목 이름 탭 | 편집 시트 (이름·아이콘·색상·단위·값, 위/아래 이동, 0으로, 삭제) |
| 키보드 | 스테퍼 버튼에 포커스 후 Enter/Space |

- 카운트 범위: 0 ~ 999,999 정수. 0에서는 −, 최대값에서는 ＋가 꺼진다.
- 스테퍼 단위: 1 ~ 1,000.
- 상단에 항목 수와 전체 합계를 보여준다.
- 항목이 없을 때 빠른 시작 프리셋(물 마시기, 푸시업, 커피, 독서)을 보여준다.
- 설정: 모든 카운트 0으로, 백업 내보내기/가져오기(JSON).

## 3. 데이터 (`js/store.js`)

```
{ version: 1, counters: [{ id, name, emoji, color, step, value, createdAt }] }
```

`localStorage`의 `counters.data.v1`에 저장. 불러올 때와 백업을 가져올 때 `sanitizeData`로 검증한다
(깨진 항목·중복 id 제거, 값 범위 보정).
