# 배색뜨개 미리보기 — 기능 명세 (v0.1, 웹 MVP)

## 1. 요구사항

1. 격자를 만들고 가로(코)·세로(단) 크기를 정하며, 칸마다 색을 칠한다.
2. 그린 격자대로 뜨개 원단(메리야스) 미리보기를 보여 준다.
3. 도안(격자) 이미지와 미리보기 이미지를 각각 기기에 저장한다. 파일명은 `knit_YYYYMMDDHHmmss.png`.

## 2. 도안 편집

| 동작 | 결과 |
| --- | --- |
| 가로·세로 입력 → 크기 적용 | 1~100칸. 왼쪽 위 기준으로 기존 그림은 유지, 새 칸은 바탕색 |
| 새 격자 | 입력한 크기의 빈 격자 (색 목록은 유지) |
| ✏️ 칠하기 | 탭/드래그로 칠하기. 이미 같은 색인 칸에서 시작하면 그 획은 바탕색으로 지움 |
| 🪣 채우기 | 같은 색으로 이어진 영역(상하좌우)을 한 번에 칠함 |
| 🧽 지우기 | 바탕색으로 칠하기 |
| ✋ 이동 | 칠하지 않고 확대된 격자를 스크롤 |
| 색 목록 | 최대 10색, 첫 색은 바탕(삭제 불가). 색 바꾸기/추가/삭제 (삭제한 색의 칸은 바탕색) |
| 확대 −/＋ | 맞춤 → 16/22/30/40px |
| 굵은 선 | 없음/4/5/10칸마다 (오른쪽 아래부터 셈) |
| ↶ / ↷ | 실행 취소/다시 실행 (Ctrl+Z, Ctrl+Y / Ctrl+Shift+Z) |
| 예시 불러오기 | 16×15 오리 도안 (처음 열 때도 이것을 보여 줌) |

- 번호는 뜨개 도안 관례대로 오른쪽 아래가 1 (코 번호 오른→왼, 단 번호 아래→위).

## 3. 미리보기

- 칸 하나 = 한 코(V자 두 다리). 코 사이 그늘, 다리의 볼록한 음영과 실 결을 그린다.
- 가로·세로 반복 1~6회로 도안을 이어 붙여 본다.
- 칠하는 동안 0.12초 간격으로 갱신된다.

## 4. 이미지 저장

- 도안 이미지: 칸 최대 40px, 번호와 안내선 포함. 미리보기 이미지: 화면의 미리보기 캔버스(최대 가로 2400px).
- PNG로 기기 다운로드 폴더에 바로 저장 (`<a download>`).
- 파일명 `knit_YYYYMMDDHHmmss.png`(저장 시각). 같은 초에 다시 저장하면 `_2`, `_3` …을 붙여 겹치지 않게 한다.

## 5. 데이터 (`js/pattern.js`)

```
{ version: 1, cols, rows, palette: ['#hex'…], cells: [palette index…], repeatX, repeatY, major }
```

`localStorage`의 `knit.pattern.v1`에 자동 저장. 불러올 때 `sanitize`로 검증한다.
